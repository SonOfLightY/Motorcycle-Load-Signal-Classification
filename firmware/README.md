# Firmware

Folder ini berisi source code mikrokontroler yang digunakan pada prototipe sistem.

## Struktur

- `esp32-s3-main/` — program utama untuk pembacaan sensor, deteksi event, klasifikasi, deteksi arah, dan pengiriman data.
- `esp32-receiver-led-p10/` — program penerima untuk menerima data dan menampilkan kapasitas parkir pada LED P10.
