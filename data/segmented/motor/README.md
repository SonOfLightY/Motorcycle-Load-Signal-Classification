# Dataset Motor 100 event
Folder ini berisi data event motor yang berasal dari potongan data mentah
data ini merepresentasikan bagian sinyal beban dinamis ketika objek motor melintas pada platform, sebanyak 10 motor dengan variasi pengendara dan kendaraan masing masing variasi sebanyak 10 kali melintas, 5 kali kearah masuk dan kali kearah keluar.
Note : Masuk dan Keluar hanya sebagai contoh kasus untuk ultrasonik, sinyal beban dinamis hanya untuk klasifikasi objek bukan arah.
